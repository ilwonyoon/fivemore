# UI 스펙 — 레퍼런스 대조

레퍼런스 이미지에서 픽셀을 직접 측정해 산출한 수치와, 현재 코드의 값을 대조한 문서다.
치수를 바꿀 때는 코드보다 이 문서를 먼저 갱신한다.

- 측정 대상: [`docs/assets/5more-core-flow-reference.png`](assets/5more-core-flow-reference.png) (1536×1024)
- 스케일 기준: Dynamic Island 실측 126.5px = 125pt → **1px ≈ 0.988pt**
- 측정일: 2026-09-09

---

## 1. 가장 중요한 발견

### 1.1 프레임은 세 화면에서 완전히 동일하다

파란 크레용 프레임의 실측값:

| 화면 | x 범위 | 폭 | y 범위 | 높이 |
| --- | --- | --- | --- | --- |
| Home | 98–464 | 366px | 288–686 | 398px |
| Camera | 588–952 | 364px | 286–684 | 398px |
| Timer | 1076–1438 | 362px | 284–682 | 398px |

폭 차이 4px, y 위치 차이 4px는 이미지 생성 노이즈다. **세 화면 모두 같은 크기, 같은 위치**이며
이는 PRD 5.4 수용 기준과 제품 원칙 2번 `One frame, three states`를 그대로 뒷받침한다.

### 1.2 프레임은 정사각형이 아니라 세로형이다

- 실측 비율 **w/h = 0.915** (364 × 398px → **360 × 393pt**)
- 현재 코드는 `frameHeight = frameWidth * 1.02` → 비율 0.98로 거의 정사각형

### 1.3 현재 코드의 명백한 위반

`FiveMore/Features/Capture/CaptureFlowView.swift`

```swift
let isTimerFocused = phase == .timer || phase == .completion
let frameWidth = isTimerFocused ? fullWidth * 0.58 : fullWidth   // ← 레퍼런스 위반
let frameHeight = min(frameWidth * 1.02, isTimerFocused ? 232 : 400)
```

타이머 진입 시 프레임을 58%로 축소하는 동작은 레퍼런스·PRD 양쪽과 충돌한다. 제거 대상.

## 2. 치수 대조표

### 2.1 레이아웃

| 항목 | 레퍼런스 실측 | 현재 코드 | 조치 |
| --- | --- | --- | --- |
| 프레임 크기 | 360 × 393pt | 최대 390 × 400pt (타이머 시 226 × 232) | 비율 0.915 고정, 축소 제거 |
| 프레임 비율 (w/h) | 0.915 | 1.02 | 수정 |
| 프레임 상단 y | 화면 상단에서 약 281pt | 가변 | 고정 |
| 좌우 여백 | 약 16pt (화면 393pt 기준) | 24pt | 조정 |
| 워드마크 높이 | 48pt (y 167–216) | 42pt 폰트 | 근접, 유지 가능 |
| 타이머 숫자 높이 | 53pt (y 726–780) | 72pt 폰트 | 축소 |
| `End early` 높이 | 22pt (y 937–959) | 시스템 기본 | 근접 |

### 2.2 프레임 하단 ~ 타이머 숫자 간격

레퍼런스: 프레임 끝 682px → 숫자 시작 726px = **44px ≈ 43pt**

현재 코드: `VStack(spacing: 18)` + controls `minHeight` → 불일치. 43pt로 조정.

### 2.3 노란 크레용 광선

레퍼런스 Timer 화면에서 측정된 노란 요소:

| 위치 | y 범위 | x 범위 | 용도 |
| --- | --- | --- | --- |
| 프레임 위 | 220–294 | 1064–1448 (379pt) | 프레임 상단 좌우 광선 |
| 프레임 아래 | 678–788 | 1066–1444 (374pt) | 프레임 하단 + 숫자 좌우 광선 |

**현재 코드에 이 요소가 전혀 없다.** 레퍼런스의 "크레용 감성"을 만드는 핵심 장식인데 누락 상태다.

## 4. 아트 디렉션 제약 (PRD 7절)

에셋 제작 시 반드시 지킬 것:

- 전문 일러스트레이터가 흉내낸 아동화가 아니라 **실제 3–6세 아동의 그림**처럼 불완전해야 한다
- 고르지 않은 선, 찌그러진 원, 영역 밖으로 나가는 색, 들쭉날쭉한 압력
- UI 본문·버튼은 가독성 높은 시스템 서체 유지. 손그림 서체는 브랜드와 큰 타이머 숫자에만
- 실제 iPhone 목업, 특정 아이 얼굴, 시스템 카메라 UI는 복제하지 않는다

## 5. 작업 순서 제안

에셋 없이도 지금 코드만으로 개선 가능한 항목과, 에셋을 기다려야 하는 항목을 분리한다.

### 5.1 즉시 가능 (에셋 불필요)

1. 타이머 프레임 축소(`* 0.58`) 제거 → 레퍼런스·PRD 위반 해소
2. 프레임 비율 1.02 → 0.915 수정
3. 프레임 하단 ~ 타이머 숫자 간격 43pt로 조정
4. 타이머 숫자 72pt → 53pt 축소
5. 좌우 여백 24pt → 16pt 조정

### 5.2 에셋 확보 후

6. 크레용 프레임을 벡터 에셋으로 교체 (P0 #1)
7. 노란 광선 추가 (P0 #4)
8. 워드마크 교체 (P0 #2, #3)
9. Hero 3~5종 + 순환 구현 (P1 #6)
10. 완료 사운드 교체 (P1 #7)
